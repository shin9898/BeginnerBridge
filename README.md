# 競走馬育成シミュレーション - Horse Racing Tycoon

Go + Ebitengine で作られた競走馬育成ゲームです。

## ゲーム概要

あなたは新人馬主として、愛馬を育て、G1レースでの勝利を目指します。

### 特徴
- 5種類のステータス（スピード、スタミナ、パワー、根性、賢さ）を育成
- 10種類のレース（G3〜G1）に出走可能
- リアルタイムレースアニメーション
- 3年間の育成期間

## 必要環境

- Go 1.21 以上
- 以下の依存関係が必要です（自動でダウンロードされます）

## インストール & 実行方法

```bash
# リポジトリをクローン
git clone <repository-url>
cd BeginnerBridge

# 依存関係をダウンロード
go mod tidy

# ゲームを実行
go run main.go
```

## 操作方法

| キー | 操作 |
|------|------|
| ↑↓ | 選択 |
| Enter / Space | 決定 |
| Esc | 戻る |
| 1, 2, 3 | メニュー選択（メイン画面） |

## ゲームの流れ

1. **タイトル画面** - Enter/Spaceでゲーム開始
2. **名前選択** - 愛馬の名前を選ぶ
3. **メイン画面** - 以下のアクションを選択
   - [1] トレーニング - ステータスを上げる（疲労が溜まる）
   - [2] レースに出走 - 賞金を獲得するチャンス
   - [3] 休養 - 疲労を回復
4. **3年経過** - ゲーム終了、成績発表

## ステータス説明

| ステータス | 効果 |
|-----------|------|
| スピード | 最高速度に影響（最重要） |
| スタミナ | レース中の速度維持に影響 |
| パワー | 加速力に影響 |
| 根性 | 終盤の粘り強さに影響 |
| 賢さ | レース運びの安定性に影響 |
